# 11. Repositório: registro-de-ponto-facial

Data: 13/10/2026

Status: Aceito

## Contexto

O projeto é um trabalho de faculdade, e o nome `ponto-facial`, com ícone e README de vitrine, o apresentava como produto. O pedido é um nome com cara de trabalho acadêmico, que diga o que ele faz, e um README simples.

## Decisão

- O repositório passa a ser `guavovic/registro-de-ponto-facial`. O GitHub redireciona os links antigos.
- O README fica enxuto, com o título "Registro de Ponto Facial": sem ícone, sem selos e sem as seções de destaque. O ícone `docs/assets/icone.svg` saiu.
- O programa continua se chamando "Ponto Facial" por dentro: janelas, pacote `io.github.guavovic.pontofacial`, artefato Maven e `.jar` não mudam (ver o ADR 0008).

## Consequências

- Os links para `guavovic/ponto-facial` continuam funcionando pelo redirecionamento do GitHub.
- O nome do repositório e o nome do programa ficam diferentes, o que é comum em trabalho acadêmico.
